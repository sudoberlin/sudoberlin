# Shubham Singh

Software engineer in Dallas working on machine learning systems. M.S. in Computer Science from UT Dallas, B.Tech in Electronics and Communication Engineering from NIT Nagaland.

My research interest is robot learning: vision-language-action models, manipulation, and how reliably a learned policy behaves when its inputs shift away from what it was trained on.

## Current research

**[Instruction-phrasing brittleness in vision-language-action models](https://github.com/sudoberlin/vla-phrasing-brittleness)**

An independent study of whether OpenVLA acts the same way when one request is worded differently. The scene, camera and robot state are held fixed in SimplerEnv and only the instruction text changes, so any change in behaviour can be traced to language. The evaluation harness, paraphrase sets and metrics are public, and the GPU runs are in progress.

## Selected projects
