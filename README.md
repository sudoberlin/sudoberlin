# Shubham Singh

**Robot learning · Vision-language-action models · Embodied AI**

I study how reliably learned robot policies behave when their inputs shift away from what they were trained on. My current work is on vision-language-action models for manipulation, and the longer goal is to build robot systems end to end, from perception and learning through to control and kinematics.

## Research

**[Instruction-phrasing brittleness in vision-language-action models](https://github.com/sudoberlin/vla-phrasing-brittleness)** (independent study, ongoing)

Does a robot policy act the same way when one request is worded differently? I hold the scene, camera and robot state fixed in SimplerEnv and change only the instruction given to OpenVLA, so any change in behaviour can be traced to language. The evaluation harness, paraphrase sets and metrics are public, and the GPU runs are in progress.

**[BetaOthello](https://github.com/sudoberlin/BetaOthello)**

A reinforcement learning agent for Othello whose value function is a Bayesian neural network, trained from self-play with variational inference. Built with Narendra Gangwani at UT Dallas.
